# Dot Net Course Tasks

Console assignment solutions implemented as separate task projects.

## Prerequisites

- Install [.NET SDK](https://dotnet.microsoft.com/download)
- Verify installation:

```bash
dotnet --version
```

## Projects

- `Task2/` - Array processing: largest/smallest values, sum, arithmetic mean, and odd elements.
- `Task3/` - `MyMatrix` class with arbitrary dimensions and row/column resizing demo.
- `Task4/` - `Article` and `Store` classes with product search by index and by name.
- `Task6/` - Ukraine-English dictionary with translation lookup by Ukrainian and English words.

## How to run

```bash
dotnet run --project Task2
dotnet run --project Task3
dotnet run --project Task4
dotnet run --project Task6
```

## Build

```bash
dotnet build Task2/Task2.csproj
dotnet build Task3/Task3.csproj
dotnet build Task4/Task4.csproj
dotnet build Task6/Task6.csproj
```
